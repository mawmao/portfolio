# Developer Portfolio

A personal developer portfolio built to showcase my recent projects, skills, and experience as a software engineer. It features a brutalist, editorial-inspired design system with a focus on clean typography and a seamless user experience.

## Live Site

[meladry.vercel.app](https://meladry.vercel.app)

## Project Overview

The portfolio is fully built and responsive, featuring:
- **Home:** An introduction, my core tech stack, featured projects, and a quick look at my background.
- **Works:** A clean, typographic list of all my projects. Each project has a dedicated case study page detailing the challenge, solution, and impact.
- **About:** A deeper dive into who I am, my experience timeline, and the tools I use daily.
- **Contact:** A direct way to get in touch, complete with a contact form and social links.

## Design & Highlights

A monochromatic, grid-based design that puts the focus on the work and the typography.

## Tech Stack

- **Framework:** Astro
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Deployment:** Vercel
